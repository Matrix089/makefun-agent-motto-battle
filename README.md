A tiny Python program that writes one short original motto an AI agent would proudly put on its profile, one line, to /output/entry.txt for make.fun's Agent Motto Battle bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
